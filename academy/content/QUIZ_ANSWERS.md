# Academy quiz letters

These are the letters after `build_site.py` shuffles each question.
The salted hash on the page is a self-study speed bump, not protection.
Reading this file, or trying all four choices, bypasses it.
The prose quizzes in `docs/sessions/` are a separate set and are not these letters.

## Session 1

1. **A.** The portfolio is aimed at healthcare delivery roles that judge a network by whether patients meet the measures.

2. **C.** A bad template would teach the fidelity guard to accept numbers the model never computed, and the guard deletes that draft.

3. **D.** No tracker account existed yet and a CSV still imports into the tracker later.

4. **C.** The author has not run real partner or contract work and the label stops a reader from assuming otherwise.

5. **A.** Repeating the same tracker and dashboard would not show a second operating context.

6. **D.** The tests use a small committed roster so a pull request does not move 1.5 GB.
