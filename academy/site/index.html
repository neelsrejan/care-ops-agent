Care-gap program · ten sessions · synthetic data

Learn the care-ops-agent, session by session.

A simulated provider network, narrated against the code that runs it. Each clip opens with what that file is responsible for, then walks the lines. Rates are computed in Python. The pages, the quizzes, and the videos are static files.

How to run it locally

The default path needs no key and no model. Deterministic templates plus the numbers Python already computed.

python -m pip install -e ".[dev]"
python -m pytest
python -m care_ops_agent.run_program

Practice edits stay on a branch you create from main. Do not merge them.
