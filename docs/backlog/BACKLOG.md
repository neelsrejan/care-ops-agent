# Backlog (portable until the Asana project exists)
- `backlog.csv`: source of truth (Issue Type, Key, Summary, Epic, Sprint, Story Points, Acceptance Criteria, Status).
- `asana_import.csv`: same items in Asana's CSV-importer shape (Name, Description, Section/Column, Tags). Import via Asana → New project → Import → CSV once Neel has a free Asana account. Sections map to sprints.
Sprints: Sprint 1 = S1–S3 · Sprint 2 = S4–S7 · Sprint 3 = S8–S10. Program work runs as weekly **PDSA cycles** (Plan-Do-Study-Act) inside the sprints.
