# Sample artifacts (SYNTHETIC)

Generated by `python -m care_ops_agent.run_program` on the committed fixture roster. They are here so a reviewer can open them without running the code. Regenerating will change bytes if the schedule or the random draws change; the tests check the calculations, not these bytes.

- `program_controls.xlsx` — charter, WBS, RAID, change log, budget burn, capacity, swimlane
- `program_controls_asana.csv` — the same leaves in Asana's CSV importer shape
- `harbor_care_gap.xml` — MS Project XML
- `rfp_tracker.xlsx` — synthetic RFP questions and library hits
- `tableau/` — extracts and the local HTML preview (not a Tableau Public workbook)
- `updates/` — one partner note per group, plus internal and steering notes
